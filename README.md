## Product experience

Habba combines brand-led Arabic/RTL presentation with commerce-oriented flows rather than acting as a simple product grid.

Key surfaces include:

- branded home and featured-product discovery;
- product detail and visual storytelling;
- guided “choose your way” discovery;
- custom drop-building flows;
- cart and upsell moments;
- direct WhatsApp conversion.

## Local development

```bash
npm install
npm run dev
```

## Habba AI mode

For free local AI behavior by default, set:

- `HABBA_AI_MODE=local`

`OPENAI_API_KEY` is optional in local mode. It can remain configured, but it will not be used unless:

- `HABBA_AI_MODE=openai`
